# Independent Title and Body Composer Implementation Plan

**Goal:** Generate configurable independent titles (default 10) and body lines (default 20), compose in selection order, and attribute feedback to the selected source material.

**Architecture:** One generation request returns JSON `{titles: string[], lines: string[]}`. PromptEngine owns the output contract and parsing; app.js owns selection and clipboard; evolve.js keeps a generation-specific exposure snapshot and separate title/body use and copy counters alongside existing weights.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, Node VM tests, GitHub Pages.

**Spec:** Confirmed requirements in this task: independently configurable counts, one selected title, multiple body lines ordered by click, preview, combined copy, selection alone does not train the library.

## Global Constraints

- Preserve existing style data and saved vocabulary weights.
- Keep DeepSeek V4 thinking disabled and expansion after rendering.
- Do not fabricate unavailable product facts; repair format once and report partial results clearly.
- Do not clear previous successful results on failed regeneration.
